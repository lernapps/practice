# Welcher Block für welche Aufgabe des Materials

| Aufgabe im Material | Block im Explainer |
|---|---|
| Kreuze die richtige Antwort an (eine) | `single-choice` |
| Mehrere Antworten können richtig sein | `multiple-choice` (mindestens eine richtige Option) |
| Ordne Bezeichnungen den Kurzbeschreibungen zu | `matching` mit `pairs` (2 bis 8 Paare) |
| Bringe in die richtige Reihenfolge | `ordering` mit `items` (2 bis 8) |
| Wie viele …? | `number` mit `answer`, `tolerance`, `mistakes` (je mit `answer` und `message`) |
| Stimmt die Aussage? | `true-false` mit `answer` |
| Rechne aus (mit neuen Zahlen je Versuch) | `generated` (Skill `lernapps-explainer`) |
| Beschreibe, erkläre, vergleiche, begründe; schreibe einen Text (offen) | `open-task`: Aufgabe, 2 bis 5 Punkte einer guten Antwort, jeder Punkt des Inhalts mit seiner `source` (der Abschnitt, in dem er steht), Punkte der Form mit `kind: form`, Musterlösung als `solution` (Skill `lernapps-explainer`). Das Kind schreibt erst selbst, auch auf Papier mit Foto, dann vergleicht es |
| Beschrifte den Plan mit A bis E | `labelled-figure` mit den Buchstaben als Marker und `matching` der Bezeichnungen |
| Info-Kasten des Materials | `note` mit Titel „Info: …“ |
| Fachwort mit Erklärung | `definition` (kommt ins Glossar) |
| Tabelle, Datumsliste | `table` |
| Zeitleiste | `timeline` mit `events` (`date` als Jahr, `label` für die Anzeige) |
| Zeichnung, Kreisdiagramm, Plan | nachgebaute Abbildung als `figure` (siehe „Abbildungen nachbauen“) und eine Aufgabe dazu |
| Etwas einzeichnen, verschieben, ablesen | eine Komponente, nur wenn kein Block passt (Skill `lernapps-explainer`, Komponenten) |
| Selbsttest des Materials | `selfAssessment` im Kapitel (Skill `lernapps-explainer-self-assessment`): Aufgaben der Seiten, das Ergebnis je Seite |
