Glossar

Die Begriffe dieser App, von A bis Z, jeder mit der Seite, die ihn erklärt.

Absorption

Eine dunkle Oberfläche nimmt das Licht auf (verschluckt es) und wirft wenig davon zurück.

Erklärt auf der Seite Licht auf Oberflächen

Empfänger

Das Auge, das Licht aufnimmt.

Erklärt auf der Seite Wie wir sehen

Halbschatten

Ein etwas hellerer Bereich, in den Licht von nur einer Lampe fällt. Dort liegt nur der Schatten der anderen Lampe.

Erklärt auf der Seite Kernschatten und Halbschatten

Kernschatten

Der völlig dunkle Bereich, in den von keiner Lampe Licht fällt. Dort überlappen sich die Schattenräume beider Lampen.

Erklärt auf der Seite Kernschatten und Halbschatten

Lichtquelle

Ein Körper, der selbst Licht erzeugt. Man sagt auch selbstleuchtender Körper.

Erklärt auf der Seite Lichtquellen

Lichtstrahl

Ein Modell für ein unendlich schmales Lichtbündel. Man zeichnet ihn als gerade Linie mit Pfeil in Richtung des Lichts.

Erklärt auf der Seite Wie sich Licht ausbreitet

Randstrahl

Ein Lichtstrahl, der genau an einer Kante des Gegenstands vorbeigeht. Zwei Randstrahlen begrenzen den Schattenraum.

Erklärt auf der Seite Schattenraum und Schattenbild

Reflexion

Eine glatte Oberfläche wirft das Licht gerichtet in eine Richtung zurück, wie ein Spiegel.

Erklärt auf der Seite Licht auf Oberflächen

Schattenbild

Die dunkle Fläche auf dem Schirm. Dort trifft der Schattenraum auf den Schirm.

Erklärt auf der Seite Schattenraum und Schattenbild

Schattenraum

Der lichtarme Raum hinter einem beleuchteten Gegenstand, der kein Licht durchlässt.

Erklärt auf der Seite Schattenraum und Schattenbild

Schirm

Eine Fläche hinter dem Gegenstand, auf der man den Schatten sieht, zum Beispiel eine Wand, eine Leinwand oder der Boden.

Erklärt auf der Seite Schattenraum und Schattenbild

Sender

Die Lichtquelle, die das Licht aussendet, zum Beispiel eine Glühlampe.

Erklärt auf der Seite Wie wir sehen

Streuung

Eine raue Oberfläche wirft das Licht ungerichtet in alle Richtungen zurück, zum Beispiel weißes Papier.

Erklärt auf der Seite Licht auf Oberflächen

Teilschatten

Der Bereich, den nur ein Teil des Lichts einer ausgedehnten Lichtquelle erreicht, weil der Gegenstand einen Teil der Lichtquelle verdeckt.

Erklärt auf der Seite Teilschatten

Umlenker

Ein beleuchteter Körper. Er leuchtet nicht selbst, sondern lenkt Licht, das auf ihn fällt, in viele Richtungen weiter, auch in dein Auge.

Erklärt auf der Seite Wie wir sehen
